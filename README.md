# 20대 청년층의 영어 학습 특성과 영어 자신감에 관한 통계적 분석

20대 청년층의 영어 학습 특성과 영어 자신감을 설문조사 데이터를 기반으로 분석한 SPSS 통계 프로젝트입니다.

---

## 프로젝트 소개

Google Forms를 활용하여 대한민국 20대 청년 90명을 대상으로 비대면 설문조사를 실시하였습니다.

수집한 데이터를 SPSS로 분석하여 영어 학습 시작 시기, 교육 유형, 영어 실력 자기평가, 영어 대화 수준, 영어 자신감 등의 관계를 통계적으로 분석했습니다.

- **프로젝트 기간** : 2025.03.25 ~ 2025.05.27
- **조사 대상** : 대한민국 20대 청년 90명
- **조사 방법** : Google Forms 온라인 설문조사



## 분석 환경

- SPSS
- Google Forms

---

## 분석 목표

- 20대 청년층의 영어 학습 특성 및 영어 자신감 파악
- 영어 학습 시작 시기에 따른 영어 실력 자기평가 차이 분석
- 영어 교육 유형에 따른 영어 실력 자기평가 차이 분석
- 영어 실력 자기평가와 영어 대화 수준 간 상관관계 분석

---

## 분석 방법

- 빈도분석
- 기술통계
- 일원분산분석(ANOVA)
- Kruskal-Wallis 비모수 검정
- Bonferroni 사후검정
- 일표본 t-검정
- 독립표본 t-검정
- 피어슨 상관분석

---

## 주요 분석 결과

### 1. 설문조사 및 기초분석

- 영어 학습 시작 시기, 학습 방법, 강점·약점 등 14개 변수 구성
- 응답자의 **55.6%**가 초등학교부터 본격적으로 영어 학습 시작
- 영어 학습 강점은 **듣기(42.2%)**, 약점은 **말하기(35.6%)**로 나타남

### 2. 교육 유형에 따른 영어 실력 차이

- **p = 0.04**

### 3. 영어 대화 수준 분석

일표본 t-검정을 통해 20대 청년층의 영어 대화 수준이 기준값(3점)보다 낮은지 검증했습니다.

- 평균 : **2.43**
- **t = -5.069**
